# House Pricing Data Set - Python for Data Analyst Certificate Coursera

## Project Overview

As a Data Analyst working at a Real Estate Investment Trust, this project focuses on evaluating housing market data to answer technical and analytical questions and build predictive models for house pricing.

The analysis explores how different housing features such as square footage, number of bedrooms, bathrooms, floors, and location impact property prices.

# Dataset Information

| Variable | Description |
|---|---|
| id | A notation for a house |
| date | Date house was sold |
| price | Price prediction target |
| bedrooms | Number of bedrooms |
| bathrooms | Number of bathrooms |
| sqft_living | Square footage of the home |
| sqft_lot | Square footage of the lot |
| floors | Total floors (levels) in house |
| waterfront | House with a waterfront view |
| view | Number of times viewed |
| condition | Overall condition of the house |
| grade | Overall grade based on King County grading system |
| sqft_above | Square footage apart from basement |
| sqft_basement | Square footage of the basement |
| yr_built | Year built |
| yr_renovated | Year renovated |
| zipcode | Zip code |
| lat | Latitude coordinate |
| long | Longitude coordinate |
| sqft_living15 | Living room area in 2015 |
| sqft_lot15 | Lot size area in 2015 |
